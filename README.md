## 題庫及湯底位置

GitHub main 最外層有 `臺灣藍鵲.txt`、`南亞夜鷹.txt`。格式為：

```text
【謎面】
學生看到的題目敘述。

【湯底】
老師提供的完整真相、解釋及 AI 判斷依據。
```

只編輯【湯底】後的內容即可補答案。不要把答案填入試算表 D/E；D/E 是題目名稱。湯底留白時可看謎面，但系統不呼叫AI。修改TXT需要重新部署，並重新進入題目建立新版本。GitHub 為公開庫，TXT 不具保密性。

## 儲存與恢復

前台每 35 秒將草稿保存至伺服器，正常登出前再保存一次。每筆問題在呼叫 AI 前先提交 SQLite 交易，回答與 Token 收到後再次提交。Render 正式資料庫固定放在持久磁碟 `/var/data/turtlesoup/turtlesoup.db`；不需要 PostgreSQL 或 DATABASE_URL 環境變數。

單一背景工作每 3 秒檢查待同步資料，將有異動學生的紀錄合併成批次寫入 Google 試算表，沒有異動就不寫。提問、草稿與登出不另行直接呼叫試算表同步。前一批尚未完成時不啟動另一批，失敗時保留 SQLite 資料並延長等待後重試；3 秒是正常同步間隔，不是完成時間保證。

畫面「已保存至伺服器」表示紀錄已提交資料庫，尚待試算表同步；「已儲存至試算表」表示同步成功。試算表暫時無法寫入時，已保存的回答仍可接續作答或正常登出。伺服器未成功保存時會回報錯誤，請保留頁面重試。首次建立資料庫時從試算表匯入既有紀錄，之後重啟直接使用持久資料庫，避免舊雲端快照覆蓋待同步答案。未完成的 AI 請求標記中斷，不自動重送付費模型。斷網、強制關閉或裝置休眠時，尚未成功送到伺服器的草稿仍可能遺失。

只允許單一服務實例與一個worker。使用期間不要排序／移動名冊，不要手動改 F～K 或隱藏分頁。試算表沒有條件式寫入，程式只能重讀檢查變動；每格接近容量上限時會停止寫入，需先封存紀錄。

## Render 與本機測試

Render 環境變數只填 GEMINI_API_KEY 和 GOOGLE_APPLICATION_CREDENTIALS，後者為 /etc/secrets/google-service-account.json。另須使用支援持久磁碟的付費 Web Service，掛載 `/var/data`（建議起始容量 1 GB）。程式會確認掛載點；未掛載時拒絕啟動，避免將普通暫存資料夾誤當成持久保存。其餘正式設定由程式固定，詳見 DEPLOY.md。

```powershell
./work/venv/Scripts/python.exe -m pytest tests --basetemp=work/pytest-run
node --test tests/autosave.cjs
```

本機預設 mock AI，保留舊版格式測試以驗證相容性。私密檔案與實際密碼不可上傳GitHub。更多部署步驟見 DEPLOY.md。

目前正式活動暫時只開放名冊「謎面1」：登入直接進入臺灣藍鵲，每場最多20次提問。謎面2設定與歷史紀錄保留，暫不開放。既有30次上限的場次也套用20次限制，超過20次的舊紀錄不刪除；作答狀況只依目前開放的第一題判定。

不再提供手動結束按鈕；滿20次自動保存並轉為唯讀，登出前保存草稿及紀錄。未滿20次可重新登入接續，舊版誤按結束的場次會重新開放。既有超過20次的問答完整保留，只能瀏覽。每次部署交付須附 GitHub 提交版本號。
